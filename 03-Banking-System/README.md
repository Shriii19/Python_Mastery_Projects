# 🏦 Banking Management System

A console-based Banking Management System built with **Python** to simulate real-world banking operations while strengthening Object-Oriented Programming (OOP), JSON file handling, business logic, and clean software engineering practices.

This is **Project 03** of the **Python Mastery Projects** roadmap.

---

# 📖 About the Project

The Banking Management System allows users to manage customers, create bank accounts, perform transactions, and maintain transaction history using local JSON files.

Unlike the previous projects, this project introduces **business rules** such as balance validation, transaction recording, and money transfers, making it closer to how real banking software works.

---

# 🎯 Project Objectives

The primary goal of this project is to learn how to design and implement a banking application while following software engineering principles.

By completing this project, you will learn how to:

- Design applications using Object-Oriented Programming
- Implement business logic
- Validate user input
- Record financial transactions
- Maintain data consistency
- Store and retrieve data using JSON
- Build modular and maintainable Python applications
