# 🏥 Hospital Management System

A console-based Hospital Management System built with **Python** to practice Object-Oriented Programming (OOP), JSON file handling, and clean software design.

This project is the second project in the **Python Mastery Projects** series. It focuses on managing patients, doctors, and appointments while introducing relationships between multiple classes.

---

## 📌 Project Goal

The goal of this project is to strengthen Python fundamentals by building a real-world application using clean architecture and industry-standard coding practices.

This project covers:

- Object-Oriented Programming (OOP)
- Multiple Class Relationships
- JSON Data Storage
- CRUD Operations
- Exception Handling
- File Handling
- Clean Code Principles

---
