# 📊 CSV Data Analyzer

A local Python-based **CSV Data Analyzer** that reads structured CSV data, cleans and analyzes it, and generates useful statistical reports.

This is **Project 05** in the **Python Mastery Projects** roadmap.

The project focuses on **CSV processing, Pandas, data cleaning, filtering, sorting, grouping, statistics, and reporting**.

---

# 📖 About the Project

The CSV Data Analyzer takes a CSV file containing structured data and performs different types of analysis on it.

For this project, we will use a small local dataset so that the main focus remains on understanding Python and data analysis concepts.
