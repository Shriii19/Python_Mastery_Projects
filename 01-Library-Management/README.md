# 📚 Library Management System

A beginner-to-intermediate Python project built to strengthen Object-Oriented Programming (OOP) and core Python concepts through a real-world application.

---

## 🎯 Project Goal

The purpose of this project is to simulate a simple Library Management System while practicing clean code and software development principles.

This project is part of my **Python Mastery Roadmap**.

---

# 📖 Features

- Add Book
- View Books
- Search Book
- Update Book
- Delete Book
- Register Student
- Borrow Book
- Return Book
- View Borrowed Books

---

# 🛠 Topics Covered

This project covers:

- Classes & Objects
- Constructors (`__init__`)
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Exception Handling
- File Handling
- JSON
- Modules & Packages
- Logging
- Type Hints
- Testing
